# مصطفى تيوب

نسخة أولية قابلة للتشغيل محلياً: واجهة عربية RTL + سيرفر Node.js يجلب القنوات والفيديوهات العامة من YouTube Data API.

## المتطلبات
- Node.js 18 أو أحدث.
- مفتاح YouTube Data API v3 من Google Cloud.

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ `npm install`.
4. انسخ `.env.example` إلى ملف باسم `.env`.
5. ضع مفتاح API مكان `YOUTUBE_API_KEY`، وغيّر `ADMIN_TOKEN` إلى قيمة طويلة وسرية.
6. نفّذ `npm start`.
7. افتح `http://localhost:3000`.

## القناة المضافة مبدئياً
`@haider_waleed` — حيدر وليد

تُحفظ القنوات في `data/channels.json`. أضف القنوات بنفس صيغة العنصر الموجود:
`{"handle":"@channel_handle","displayName":"اسم المدرس","subject":"الفيزياء","enabled":true}`

## إضافة قناة عبر API الإدارة
أرسل POST إلى `/api/admin/channels` مع ترويسة `x-admin-token` المطابقة لـ `ADMIN_TOKEN` وجسم JSON:
`{"handle":"@channel_handle","displayName":"اسم المدرس","subject":"الفيزياء"}`

## ما الذي تعرضه النسخة؟
- قنوات المدرسين وصورهم وأسماءهم.
- آخر 30 فيديو من قائمة uploads لكل قناة.
- عنوان الفيديو والصورة وتاريخ النشر والمدة.
- مشغل يوتيوب مضمّن داخل الموقع.
- بحث محلي في المحاضرات وتصنيف حسب المادة.

## ملاحظات مهمة
- لا تضع مفتاح API داخل ملفات `public` أو JavaScript المتصفح؛ مكانه `.env` على السيرفر فقط.
- هذه نسخة تأسيسية وليست بعدُ منصة إنتاج مكتملة: لا يوجد تسجيل دخول للطلاب، ولا لوحة إدارة رسومية، ولا قاعدة بيانات دائمة بعد.
- بيانات القنوات العامة والفيديوهات تُجلب وفق واجهة YouTube Data API. بعض أنواع منشورات المجتمع أو المحتوى الخاص/المقيّد لا تظهر عبر هذا المسار.
- الفيديو يبقى مستضافاً لدى YouTube ويُعرض عبر المشغل الرسمي؛ لا تُنزّل أو تعِد استضافة فيديوهات المدرسين دون إذن.
- أضف نطاق الموقع إلى إعدادات API وقيود المفتاح عند النشر، واستخدم HTTPS.
